# Assessment brief (summary)

**Module:** Procedural Programming (ITPPA1), BSc Information Technology, Eduvos, NQF Level 5. Individual assessment.

| Question | Task |
|---|---|
| 1 | **Cafeteria Order System** in C++: read a customer's name and surname, let them choose up to 8 items from a menu, validate the selections, add up the bill, apply a 10% discount when the total exceeds R100, display the bill and write the customer's name, surname and final bill to `CafeteriaBill.txt` with a success or error message |
| 2 | **Shopping Cart Program**: design a flowchart (sequence, decisions, calculations, file handling) and write the algorithm for a cart where items and quantities are chosen, a 5% discount applies above R200, and the bill is saved to a text file |
| 3 | **Student Scores**: store the scores of 5 students in an array and use loops to calculate the average, highest and lowest scores and to list the scores in the order entered |
| 4 | **Bank Account Management System**: menu-driven program with the functions `createAccount`, `depositMoney`, `withdrawMoney`, `checkBalance` and `displayAccountDetails` (signatures given in the brief), enforcing the rules that deposits and the initial deposit are greater than 0 and withdrawals cannot exceed the balance |

The full brief is the property of Eduvos.
